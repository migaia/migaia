# `@migaia/tray` usage

`createTray()` admits one complete static entry set. Call `ready()` before `get()`; unknown, pending, failed, and terminal entries are unavailable. Graph owns primary release, value revocation, auxiliary `context.own()`, and lifecycle Promise identity. Tray core adds no timeout, scheduler, transport, or realm termination policy.

Dynamic/domain composition belongs to `docs/tray/tray-domain-adapters.sdd.md`; cross-realm ownership belongs to `docs/capability/capability-graph-cross-realm.sdd.md`.
