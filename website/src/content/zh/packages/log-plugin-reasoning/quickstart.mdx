# 推理文本与审计

原样输出文本片段，将完整阶段记录为静默审计条目。

当前为仓库中的未发布实现；工作区可使用以下包，面向仓库外的安装须等待相应版本发布。

```bash
pnpm add --workspace @migaia/log-host @migaia/log-plugin-reasoning
```

## 完整示例

```ts
import { createLogHost } from '@migaia/log-host'
import { reasoningPlugin } from '@migaia/log-plugin-reasoning'

const log = createLogHost({
  plugins: [
    reasoningPlugin({
      write: (text) => {
        globalThis.console.log(text)
      },
      labels: { thinking: 'Plan' }
    })
  ]
})
log.startThinking()
log.thinking('check cache')
log.startResponse()
log.response('42')
log.endResponse()
await log.shutdown('manual')
```

日志方法同步返回，读取交付结果前等待 `flush()`；退出前等待 `shutdown('manual')`。持久日志的追加、提交与读取仍按自身存储契约拒绝，不能用日志方法的非抛出保证代替事务结果。
