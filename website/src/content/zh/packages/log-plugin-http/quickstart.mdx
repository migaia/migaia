# HTTP 日志交付

使用借用的请求能力上传规范条目包络；批量、重试与超时交给宿主。

当前为仓库中的未发布实现；工作区可使用以下包，面向仓库外的安装须等待相应版本发布。

```bash
pnpm add --workspace @migaia/log-host @migaia/log-plugin-http
```

## 完整示例

```ts
import { createLogHost } from '@migaia/log-host'
import { batchFeature, retryFeature } from '@migaia/log-host/features'
import { httpPlugin } from '@migaia/log-plugin-http'

const log = createLogHost({
  plugins: [
    httpPlugin({
      url: 'memory-only',
      features: [batchFeature({ maxSize: 2 }), retryFeature({ attempts: 2 })],
      fetcher: async (_url, request) => {
        console.log(request.body)
        return new Response(null, { status: 200 })
      }
    })
  ]
})
log.log('info', 'one')
log.log('info', 'two')
await log.shutdown('manual')
```

日志方法同步返回，读取交付结果前等待 `flush()`；退出前等待 `shutdown('manual')`。持久日志的追加、提交与读取仍按自身存储契约拒绝，不能用日志方法的非抛出保证代替事务结果。
