# 持久日志与恢复接口

提供独立的变更日志、预写日志、撤销插件和可借用日志存储。

当前为仓库中的未发布实现；工作区可使用以下包，面向仓库外的安装须等待相应版本发布。

```bash
pnpm add --workspace @migaia/log-host @migaia/log-plugin-durable
```

## 完整示例

```ts
import { createLogHost } from '@migaia/log-host'
import { binlogPlugin, memoryLogStore } from '@migaia/log-plugin-durable'

const store = memoryLogStore()
const log = createLogHost({ plugins: [binlogPlugin({ store })] })
await log.binlog.append('order.created', { id: 'o1' })
console.log(await log.binlog.read(1))
await log.shutdown('manual')
```

日志方法同步返回，读取交付结果前等待 `flush()`；退出前等待 `shutdown('manual')`。持久日志的追加、提交与读取仍按自身存储契约拒绝，不能用日志方法的非抛出保证代替事务结果。
