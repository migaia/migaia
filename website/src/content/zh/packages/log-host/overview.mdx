# 异步日志宿主

组合输出插件与独立特性；宿主负责有序交付、失败通道、排空及关闭。

## 所有权

以 `createLogHost` 建立宿主，按需安装插件。宿主拥有插件注册和交付生命周期；应用提供的 console、stdout、fetcher、writer、process 与持久存储仍为借用能力，由原所有者结束使用。

## 使用边界

输出插件只执行自己的介质工作。批量、重试、超时、门槛和过滤复用宿主特性；结构化错误投影由宿主统一提供。HTTP 不消费格式化文本，宿主格式对它跳过，不能为它配置输出级格式。

[快速开始](./quickstart)给出可完整结束生命周期的示例。当前包尚未发布，不代表网站运行时依赖已经迁移。
