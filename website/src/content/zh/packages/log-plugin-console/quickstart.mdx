# 控制台输出

借用控制台与标准输出，并使用美化、结构化或纯文本格式。

当前为仓库中的未发布实现；工作区可使用以下包，面向仓库外的安装须等待相应版本发布。

```bash
pnpm add --workspace @migaia/log-host @migaia/log-plugin-console
```

## 完整示例

```ts
import { createLogHost } from '@migaia/log-host'
import { consolePlugin, prettyFeature } from '@migaia/log-plugin-console'

const log = createLogHost({
  plugins: [consolePlugin({ console: globalThis.console })],
  features: [prettyFeature({ color: 'never', timestamp: false })]
})
log.log('info', 'user=%s', 'alice')
log.raw('progress\r')
await log.shutdown('manual')
```

日志方法同步返回，读取交付结果前等待 `flush()`；退出前等待 `shutdown('manual')`。持久日志的追加、提交与读取仍按自身存储契约拒绝，不能用日志方法的非抛出保证代替事务结果。
